# Changelog

## [Unreleased]

### Cambiado

- La configuración adopta las reglas de mapas, armas y validación de
  clientes de ZoneMod 4v4 v2.9.2b y conserva las reglas propias de T1.
  El modo prescinde de la pausa automática.
- La instalación requiere la configuración de validación de clientes
  y Plugin Manager de L4D2-Competitive-Rework.

- El ZIP instalable contiene la configuración de `t1_zm` para copiarla
  sobre una instalación de L4D2-Competitive-Rework.

### Desarrollo

- Make y GitHub Actions generan y validan el ZIP de configuración sin SDK.
